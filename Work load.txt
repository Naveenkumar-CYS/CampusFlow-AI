This is the actual ERP — every workflow in the doc depends on this existing first, so it should be the person most comfortable with backend architecture and database design.

This is your "Smart Automation" differentiator — the part judges will interrogate hardest, so it needs one owner end-to-end rather than being split, so the person can explain the full event→rule→AI→action chain fluently.
